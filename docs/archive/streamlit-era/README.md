# Earlier Streamlit-era design

These documents describe the earlier Streamlit application and its original product plan. The deployed system has since moved to a static frontend, FastAPI backend and PostgreSQL architecture. The old Streamlit application source is not included in this cleaned copy; it remains in the untouched original project.

Retained for project history only:
- ARCHITECTURE.md
- PROJECT_DESCRIPTION.md
- PRD.md

For the current system, see ../../ARCHITECTURE_CURRENT.md.

To run this old interface locally, install its optional dependencies with python -m pip install -r requirements-legacy.txt, then use the historical command documented in PROJECT_DESCRIPTION.md. These packages are intentionally excluded from the current backend runtime.

- README_TRENDS_WIDGET.md — original static-export widget delivery notes.
- RULES.md — superseded project conventions written for the Streamlit application.
